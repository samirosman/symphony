# Symphony 0.1.0 preview 3

Easier to install. Same Symphony as preview 2.

- **One download.** Go to [the Symphony site](https://tdemers218.github.io/symphony/)
  and click **Download**. It picks the right file for your computer.
- **One Mac launcher** for every Mac, Apple chip or Intel.

Everything new since preview 1 is in the
[preview 2 notes](https://github.com/tdemers218/symphony/releases/tag/v0.1.0-preview.2).

## Installing
Open the launcher and click **Install Symphony**. Builds aren't signed
with an Apple Developer ID, so the first time you open the launcher,
macOS asks you to allow it in System Settings > Privacy & Security
("Open Anyway"). Windows may show SmartScreen: click More info > Run
anyway.
